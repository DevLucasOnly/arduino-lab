# 🔌 Arduino Lab

Coleção de projetos práticos com Arduino, feitos em protoboard, explorando conceitos de eletrônica, leitura de sensores, controle de LEDs e lógica de programação embarcada.

## 📂 Projetos

| Projeto | Descrição | Componentes principais |
|---|---|---|
| [Seta de carro com potenciômetro](./seta-carro/README.md) | Simula as setas de um carro: LED direito/esquerdo pisca conforme a posição de um potenciômetro, com botão para pisca-alerta. | Potenciômetro, botão, LEDs |

*(novos projetos serão adicionados aqui conforme forem desenvolvidos)*

## 🛠️ Tecnologias e ferramentas

- Arduino Leonardo
- Linguagem C/C++ (Arduino IDE)
- Protoboard e componentes eletrônicos básicos (LEDs, resistores, potenciômetros, botões, encoder rotativo)

## 📖 Sobre

Este repositório reúne exercícios práticos de eletrônica e programação embarcada, desenvolvidos como parte dos meus estudos em Engenharia Elétrica. Cada pasta contém um projeto independente, com seu próprio código-fonte e README explicando o funcionamento, os componentes usados e o esquema de ligação.
